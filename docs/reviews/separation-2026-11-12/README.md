# Independent separation review

Claude Fable5.2 ran twice with read-only Read/Glob/Grep tools under restricted
mode, no command execution or provider access, and5USD/2USD ceilings. The user
authorized independent source review. Recorded list-price costs were2.9274188USD
and1.3045358USD. No tests were delegated to Claude.

Round1 found no blocker in the read ownership/authentication/configuration paths
and one valid document-example publication ownership issue. Dia now starts only
its document outbox owner in remote modes; inline mode retains direct identity
projection. Foreign notices are rejected rather than silently accepted.

Round2 closed that finding and found no defect in the reviewed local/inline
behavior or lifecycle. It is a bounded source review, not a full security audit.
The parent subsequently confirmed the new native ownership regression against
both PostgreSQL and MongoDB: document delivery deletes only document notices,
while identity wallet notices remain byte-for-byte unchanged until their own
owner delivers them. The affected native packages passed3.054s/6.537s.
